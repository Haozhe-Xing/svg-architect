# zh_dense — 中文信息密集

> 技术文档插图风格：浅色体系、高信息密度、结论先行。专为 mdBook / 博客 / 教学材料中
> 以 100% 原尺寸嵌入的自包含插图设计。一张图就是一小节内容，不是配图点缀。

- **平台**：`doc_figure`（680×H，H 400–1000 弹性）
- **适用**：算法原理图、公式推导、机制对比、决策矩阵、数据流拆解
- **不适配**：营销封面、情绪化海报（用 neubrutalism / glass_premium）

| Blue-tint | `#DBEAFE` | 蓝节点填充 |
| Blue-ink | `#1E3A8A` | 蓝节点内文字 |
| Green | `#059669` | 语义色：正确 / 收敛 / 增益 |
| Green-tint | `#D1FAE5` | 绿节点填充 |
| Green-ink | `#065F46` | 绿节点内文字 |
| Red | `#DC2626` | 语义色：错误 / 发散 / 损失 |
| Red-tint | `#FEE2E2` | 红节点填充 |

| Formula-border | `#F59E0B` | 公式框边（1.5px） |

**语义色必须语义化**：绿=好、红=坏全图一致，不得用红蓝做纯装饰。

## 字体与字号

字体栈（唯一允许）：

```
Segoe UI, PingFang SC, Noto Sans SC, Microsoft YaHei, system-ui, sans-serif
```

| 层级 | 字号 | 字重 | 备注 |
|------|------|------|------|
| H1 | 16–17px | 700 | 左上角，紧跟一行 12px 副标题（`#475569`，正常字重） |
| H2 | 14px | 600 | 区块标题 |
| Body | 13px | 400 | 节点内文字、表格内容 |
| Caption | 12px | 400 | 图例、脚注（下限，不得再小） |

## 版式结构（自上而下）

1. **标题块**（左上）：H1 + 副标题，高度约 44px
2. **结论先行**：标题块正下方一行 Body 文字，加 `#2563EB` 左侧 3px 竖条标记，一句话给出本图结论
3. **图例**（右上，与标题同行）：色块 10×10 + 12px 文字，横向排布；绿红语义色必须入图例
4. **信息主体**：≥3 个信息块，从以下形态中组合——
   - 流程步骤（蓝描边圆角矩形，rx=6，箭头连接）
   - 公式框（Formula-bg 底 + Formula-border 边，公式文字 13px 居中）
   - 对比表格（行高 ≥24px，`#E2E8F0` 分隔线，表头 600 字重）
   - 数据条（tint 填充条 + 描边，数值 13px 右对齐）
5. **脚注**（可选，底部）：12px `#64748B`，用于"* 数值为示意"等来源说明

## 密度规则（区别于公众号风格的核心）

- 单张图信息块 ≥3，元素（节点/行/条/公式）总数 ≥8
- 块间距 8–12px，块内边距 8–10px，不留大面积空白
- **禁止单一焦点构图**：不允许"一个巨大图形 + 少量文字"的极简布局
- 每 680×200px 区域内至少有 1 个信息块或 3 个文字元素
- 画布底部整块空白不得超过 40px（宁可收缩画布高度）

## 硬约束（validator 相关）

1. **所有文字一律深色**（Ink 系 / *-ink 系 / Formula-ink）——validator 按画布底色
   `#F8FAFC` 计算对比度，白色或浅色文字会被判 `E_CONTRAST_LOW`。彩色只给描边、
   填充 tint、箭头，不给文字。
2. 字号下限 12px（`doc_figure` 平台档），低于即 `E_FONT_SIZE_TOO_SMALL`
3. ID 一律 `svga-<slug>-` 前缀；箭头 marker、渐变定义都要带前缀
4. viewBox 宽度固定 680，高度 400–1000，超出范围平台识别失败

## 负向约束（禁止项）

- ❌ 深色/黑色画布底
- ❌ 渐变文字、渐变节点填充
- ❌ 柔和阴影（drop-shadow / feDropShadow）——分层用 1px 边框 + tint 填充实现
- ❌ ASCII 框线（`+--+`、`|` 等字符画结构）
- ❌ 大面积留白、单一焦点、装饰性圆点/光晕
- ❌ 每元素独立字体栈（全图共用一份，写在根 `<svg>` 或首个 `<g>` 上）
