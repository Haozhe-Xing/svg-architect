# Clean Teaching Visual Specification（干净教学风）

> 面向技术教学、课程讲义、博客解释图、模型结构图的浅色卡片式 SVG 风格。
> 它比 `zh_dense` 更克制、更留白；比 `minimal_clean` 信息量更高；核心目标是让复杂机制看起来清楚、温和、可讲解。

## 适用场景

- Transformer / LLM / Diffusion 等模型结构解释图
- 算法流程、训练流程、推理流程、系统模块拆解
- 教材、课程、博客、mdBook 中的机制说明图
- 需要展示主流程 + 旁注 + 模块演进 + 残差/跳连的技术图

## 不适用场景

- 营销封面、活动海报、强情绪传播图
- 极高密度表格/公式推导（优先使用 `zh_dense`）
- 暗黑科技海报（优先使用 `tech_dark`）

## 平台建议

- **首选**：`doc_figure`（680×H，H 400–1000 弹性）
- **可选**：`wechat_article`（1200×500，用于公众号文章中的教学插图）
- **不建议**：`wechat_cover`（该风格不是强封面视觉）

## 版式结构

### 1. 标题区

- 左上角标题 + 一行副标题。
- 标题不做大字冲击，保持教学语气。
- 可在右上角放 2–4 个图例 chip。

### 2. 主流程区

- 使用纵向或横向主流程作为视觉骨架。
- 主路径节点采用白底圆角卡片，语义色描边或顶部小色条。
- 箭头用 `#2563EB`，线宽 1.5–2px。
- 节点之间保留 10–16px 间距，不挤压。

### 3. 分区背景

- 大区域可用淡色 tint 背景（如 Attention 区、FFN 区），透明度不要过高，避免糊成一片。
- 分区标题放在左上角，用语义色深色文字。
- 大分区只做轻描边，不使用强阴影。

### 4. 旁注卡片

- 左右两侧可放 1–3 个说明卡片。
- 每张卡片聚焦一个概念："为什么需要残差"、"模块替换"、"N 层堆叠"等。
- 旁注使用浅黄、浅紫、浅蓝底色，文字仍保持深色。

### 5. 残差 / 跳连

- 残差连接建议用红色虚线或弧线：`stroke="#DC2626" stroke-dasharray="5 5"`。
- 必须加文字标签，避免读者误解为错误路径。
- 标签用深红 `#991B1B`，不使用白字。

## 视觉特征

- 圆角：模块 `rx=8–12`，小节点 `rx=6–8`。
- 阴影：轻量即可，如 `drop-shadow(0 2px 6px rgba(15,23,42,0.08))`。
- 边框：1px `#E2E8F0`，重点节点可用 1.5px 语义色描边。
- 留白：比 `zh_dense` 更宽松，块间距 12–20px。
- 信息密度：中高密度；一张图讲清一个机制，但不追求表格化压缩。

## 与其他风格的区别

| 对比对象 | 区别 |
|----------|------|
| `zh_dense` | `clean_teaching` 更柔和、更卡片化、更留白；`zh_dense` 更紧凑、更表格/公式密集。 |
| `minimal_clean` | `clean_teaching` 信息块更多，允许流程、旁注、分区并存；`minimal_clean` 更偏品牌/概念表达。 |
| `bento_info` | `clean_teaching` 有明确主流程骨架；`bento_info` 更偏格栅全景。 |

## 硬约束

1. 所有文字使用深色：Ink、Ink-soft 或语义深色，不使用白字。
2. `doc_figure` 下最小字号 ≥12px。
3. 所有 `id` 统一使用 `svga-<slug>-` 前缀。
4. 背景必须为浅色纯色，禁止深色画布。
5. 不使用外部图片、外部字体、`foreignObject`、`script`。
6. 不使用大面积渐变、霓虹光效、复杂模糊背景。

## 推荐构图模板

### 模板 A：模型层结构图

- 中央：纵向主流程节点
- 左侧：概念说明卡片
- 右侧：模块替换/演进卡片
- 背景：按子层分为 2–3 个淡色区域
- 红色虚线：残差连接

### 模板 B：算法机制解释图

- 顶部：一句结论
- 中部：横向步骤链路
- 底部：关键公式 / 注意事项 / 输入输出对照

### 模板 C：系统模块教学图

- 左侧：输入与上下文
- 中央：处理模块栈
- 右侧：输出与效果
- 底部：异常路径或缓存/优化说明
